The four plugins

Each does one job well. Use any alone; together they form a full orchestration substrate for coding agents.

🌐B-01

Browser structupath.browser

A live, drivable web browser in a Herdr pane. When your coding agent drives Chrome, you see the same session — click, type, scroll, record to WebM. One isolated session per workspace.

repo guide
🛡️G-01

Guard structupath.guard

Advisory cross-agent command policy. Observes rendered terminal text, audits and alerts on matches, and best-effort interrupts visible shell input — with an honest contract about what it can and can't see in agent TUIs.

repo guide
🐝S-01

Swarm structupath.swarm

Try a task N ways in parallel, keep the best. Every agent gets its own git worktree and branch; agents commit locally and never push. You are the merge gate — review-first harvest, layered safe cleanup.

repo guide
🎩C-01

Conductor structupath.conductor

Run a role-differentiated team — builder, validator, reviewer — each a real, attachable pane, driven by an orchestrating agent. Conductor currently owns its worktree and harvest flow; it does not delegate those operations to Swarm.

repo guide
§2

Install

Install commands documented by each plugin repository. Review source, manifests, and plugin-specific requirements before installation.

# pick what you need — or take the whole suite
herdr plugin install StructuPath/herdr-browser
herdr plugin install StructuPath/herdr-guard
herdr plugin install StructuPath/herdr-swarm
herdr plugin install StructuPath/herdr-conductor

# health check
herdr plugin list
herdr plugin action list

Write-capable plugins and agents are trusted same-user principals. Worktrees make changes reviewable; they are not a sandbox or operating-system security boundary.
